## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| localStorage → React state | madgy_caregiver value is cast to union type on read; could be any string if manually tampered |
| React state → Firestore write | identity value flows directly into loggedBy field; Firestore rules check auth but not loggedBy content |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | Tampering | localStorage `madgy_caregiver` manual edit | accept | Only affects display attribution ("Me"/"Wife"); no access-control significance; private family device; Firestore auth rules enforce the real security boundary |
| T-02-05 | Spoofing | identity state → addLog loggedBy | accept | No real identity verification in MVP; two-person household; anonymous auth gates writes; loggedBy is a display label, not a permission |
| T-02-06 | Denial of Service | disabled guard in handleLog | mitigate | `if (!identity) return` prevents writes with null identity even if UI disabled state is bypassed; handled in Task 2 handleLog guard |
| T-02-SC | Tampering | npm installs | accept | No new npm packages in this plan — no new dependencies added |
</threat_model>
